ATK Connect Agent

AI-powered agent for aerospace mission simulations –
describe what you need in natural language, and let the LLM drive ATK.

Built on DeepSeek / OpenAI / Qwen • ATK CONNECT Mode • ReAct Loop

GitHub Learn More ↓

Capabilities

🛰️

Orbit Design

Keplerian, Cartesian, SGP4, and TLE orbital elements. Set semi-major axis, inclination, RAAN, and more with natural language.

📡

Ground Stations

Create and manage ground stations anywhere on Earth. Compute access times and coverage windows.

🎯

Maneuver Planning

Astrogator-based impulsive and finite-burn maneuver planning for orbit transfer and rendezvous.

🔭

Sensor Modeling

Configure sensors (cone, rectangular, complex) on satellites and facilities for coverage analysis.

🧠

LLM-Powered

DeepSeek, OpenAI, or Qwen backends. ReAct loop: Think → Act → Observe → Verify → Conclude.

💾

Scenario Management

Create, save, and load complete simulation scenarios. Export ATK scenario files for offline use.

Quick Start

1

Clone the repo

$ git clone https://github.com/lihaichuan6686/atk-connect-agent.git
2

Install dependencies

$ cd atk-connect-agent && pip install -r requirements.txt
3

Configure

$ cp config.py.example config.py # Edit config.py — set ATK path and LLM API key
4

Run the agent

$ python atk_agent.py >> create a scenario "LEO" from 5 Nov 2022 to 8 Nov 2022 >> create a satellite "Sat1" with altitude 550 km, inclination 97.5° >> create a ground station "Beijing" at (39.9, 116.4) >> run the simulation

Use as a Library

# Simple 4-line integration from atk_agent import ATKAgent agent = ATKAgent(api_key="sk-xxx", model="deepseek-chat") agent.start_atk() agent.connect_atk() # Describe your mission in natural language reply = agent.chat("Create a sun-synchronous orbit at 600 km") print(reply)
